# Context Loom

**Context Loom** ist ein Git-basierter Arbeitsraum für strukturierte Kontexte, Recherche, Wissensarbeit, Softwareprojekte und wiederverwendbare Engineering-Ansätze.

Frühe Themen entstehen häufig in [`_workbench`](https://github.com/context-loom/_workbench) und werden bei ausreichender Eigenständigkeit in eigene Repositories überführt.

Zur Orientierung:

- [**Context Loom Index**](https://github.com/context-loom/.github/blob/main/INDEX.md) – Repositories und wesentliche Workbench-Themen
- [**Organisation & Vorgaben**](https://github.com/context-loom/.github) – gemeinsame Arbeits-, Agenten- und Housekeeping-Regeln
