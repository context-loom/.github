# Context Loom

**Context Loom** ist ein gemeinsamer, Git-basierter Arbeitsraum für strukturierte Kontexte, Recherche, Wissensarbeit, Softwareprojekte und wiederverwendbare Engineering-Ansätze.

Inhalte werden weitgehend mit KI-Unterstützung erzeugt und gepflegt; direkte menschliche Ergänzungen und Korrekturen bleiben ausdrücklich vorgesehen.

## Orientierung

Für Mitglieder der Organisation steht eine separate **interne Ansicht des Organisationsprofils** mit Projektindex, laufenden Schwerpunkten und übergreifenden Vorgaben zur Verfügung.
